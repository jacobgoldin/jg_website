# Research PDF links

Stable browser-viewable PDFs are served by GitHub Pages at https://jacobgoldin.github.io/jg_website/pdfs/ .

The `pdfs/` filenames intentionally contain no dates. When a paper is revised, update its corresponding stable PDF rather than changing the Google Sites link.

`pdf-links.json` records the original source filename, Git blob SHA, size, and stable URL for this migration. All original files are retained so existing links continue to work. The initial copies preserve the versions linked by the research page, including `SNAP 10-8-19.pdf` for Issuance and Incidence.
